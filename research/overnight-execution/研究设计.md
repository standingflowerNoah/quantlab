# 尾盘买入-次日开盘卖出（隔夜执行）策略研究设计

> 2026-09-10 立项。**本地研究分支**：工作隔离于 `research/overnight-execution/` 文件夹（不建 git 分支），研究脚本放 `scripts/`，命名前缀 `overnight_`，产出报告放 `reports/`，结论回写本文档。
> 策略形式：T 日尾盘买入 → T+1 日开盘卖出，持有约 17.5 小时，收益段 = `open_{t+1} / fill_t − 1`。

## 0. 问题定义与先验

### 与已有结论的关系

- `overnight_mom_20`（三度证伪、单腿 2024 年 −5.3%）是**低频选股因子**：用过去 20 日隔夜收益排名，持有 20 日。它证伪的是"过去隔夜强 → 未来 20 日强"。
- 本研究是**事件级执行策略**：持仓期就是隔夜段本身，赚的是 `close_t → open_{t+1}` 这一段。两者是不同的问题，不能互相推断；但 overnight_mom_20 组合层的失败提示隔夜信息在组合层兑现能力弱，需降低先验预期。

### 两个结构性先验（不友好，Phase 1 必须先用自家数据验证）

1. **A 股隔夜段平均收益历史为负**。文献共识与美股相反：A 股日内段（open→close）平均为正、隔夜段（prev_close→open）平均为负，解释与 T+1 制度下的尾盘博弈 / 开盘竞价博弈有关。若无条件隔夜段为负，本策略只有条件化（选对股票 / 选对日子）才可能为正。
2. **换手成本是头号敌人**。每日全仓买+卖 = 年换手约 500 倍。往返成本估算：
   - 买入：佣金 ~0.01%（万一免五）
   - 卖出：佣金 0.01% + 印花税 0.05%
   - 滑点（尾盘买入 + 开盘竞价卖出）：各按 0.03~0.07% 估
   - **合计往返 ~0.15%**；年化摩擦 ≈ 0.15% × 250 ≈ **37%/年** → 毛收益需 **>15bp/日** 才有肉，这在无条件情形下几乎不可能，条件化也极难。研究价值在于诚实测出"差多少"和"哪段子集最接近"。

## 1. 数据盘点（Phase 0，已具备 ✅）

| 数据 | 覆盖 | 用途 |
|---|---|---|
| kline_daily（不复权） | 2022-01-04 起 | `close_t`（=收盘集合竞价价）作尾盘买入近似，`open_{t+1}`（=开盘集合竞价价）作卖出价；2022-2024 的长样本回测 |
| kline_1min（fsdb 源） | 2025-01-02 起（约 5.19 亿行） | 精确执行价：14:55/14:56 bar 作尾盘买点；T+1 首根 bar open 作卖点；开盘段成交量可成交性分析 |
| dividend_events | 1990–2026 | 隔夜段除权除息调整（关键陷阱，见下） |
| fsdb 日线兜底 | 含 amount/float_mv | 流动性分组、兜底补数 |

**复权陷阱（必须先处理）**：kline_daily 不复权，`open_{t+1}/close_t − 1` 在除权除息日含虚假跳空（送转残差可达 −27%）。方案：
- 主口径：用 dividend_events 对除息日样本做前瞻调整（fenhong/songzhuangu/peigu 精确复权因子）；
- 旁证口径：直接剔除 T+1 为除权除息日的样本，对比两者差异作敏感性。
- 注意 kline_daily 中 `open` 是开盘价（不复权真实开盘），调整只需对隔夜段分子分母按事件复权，不能整段用后复权价（会引入前视）。

## 2. 研究问题分层

- **Q1 基础事实**：全市场无条件隔夜段的时序统计（日均值、分位数、分年度 2022-2026）；隔夜段 vs 日内段收益分解（验证"隔夜负/日内正"）；分市场状态（牛熊/波动率分位）。
- **Q2 截面条件化**：哪些股票的隔夜段为正？分组维度：size 十分组、amihud 流动性、波动率、换手率、尾盘动量、当日涨跌停状态、ST/非 ST。
- **Q3 时序条件化**：哪些日子隔夜段为正？前日尾盘方向、周内效应（周四/周五）、节前节后、市场隔夜消息环境（用指数隔夜段代理）。
- **Q4 执行可行性**：开盘集合竞价可成交性（T+1 首 15 分钟成交额占全日比、按 size 分层）；微盘股开盘冲击成本；涨跌停/停牌/一字板约束的实操处理。
- **Q5 组合可行性**：最优条件组合的扣费净收益、与生产模型（size+amihud top100，20 日调仓）的关系——是替代还是叠加（叠加形式：生产持仓改尾盘买入以吃隔夜段？）。

## 2.5 伪日线构造与存量因子复用（2026-09-11 增补）

核心思想：**把执行时刻定义为"当日收盘"**。在决策时点 t* = T 日 14:56，用 1min bar 聚合出"伪日线"，使全库存量因子（38 风格 + Alpha191 OHLCV 类，共 218 因子中纯量价者）无需重研即可直接计算，且因子值在 t* 天然 PIT 干净——比"收盘后算因子、次日执行"少一天信息延迟，也不存在隐性前视。

### 伪日线口径（2025+，1min 聚合）

| 字段 | 定义 | 备注 |
|---|---|---|
| open | 当日 09:30 bar open | 真实开盘 |
| high / low | [09:30, 14:56] 区间 1min max/min | ≤ 真实日线 high/low（amplitude 类因子轻微低估） |
| close | 14:56 bar close | **= 买入 fill 价，因子与执行同一口径** |
| vol / amount | 截至 14:56 累计求和 | ≈ 全日的 95%，跨日口径一致，不影响横截面 rank |
| 涨跌停判定 | 伪 close vs 当日涨停/跌停价 | 14:56 封板即视为不可买/可买判定依据 |

### 因子计算方式

- **混合窗口**：回看窗口内，T-1 及以前用真实日线，最新一日用伪日线。量类因子（turnover_20 等）误差约 4%/窗口长度、价类因子（reversal、mom、amihud 的价格部分）误差极小，可接受；不做精调，文档如实标注口径。
- **严格口径（对照组）**：因子仅用 T-1 及以前真实日线，零混合。A/B 对比验证混合口径不引入偏差。
- **2022-2024 延迟口径**：无分钟数据 → 因子用 T-1 真实日线（滞后一日）、买入价 T 日 close。仅作长样本方向参考，不与 2025+ 主口径混用。
- **非量价因子**（财务/事件类）：as-of 原则不变，与伪日线方案正交。

### 工程约定

- 独立脚本 `scripts/overnight_*.py`，研究期 in-memory + parquet 直读（项目惯例），因子缓存落 `data/lake/factor/overnight/`（独立命名空间，不污染生产因子目录）；不改动 daily_pipeline / minute_feat。
- 全量回看窗口约 250 交易日 × 全市场 1min 聚合，单次计算控制在分钟级（duckdb 直读 parquet 分区裁剪）。

## 4. 回测与执行假设

| 环节 | 假设 |
|---|---|
| 买入价 | 主口径：T 日 14:56 1min bar close（连续竞价末段）；近似口径：T 日 close（2022-2024 可用） |
| 卖出价 | T+1 首根 1min bar open（≈日线 open，开盘集合竞价价） |
| T+1 合规 | 尾盘买→次日开盘卖，天然满足 ✅ |
| 涨停约束 | T 日收盘涨停/14:56 涨停价封板的不可买，剔除 |
| 跌停约束 | T+1 开盘跌停的不可卖，递延至首个可卖开盘价（计价到实际卖出） |
| 停牌 | T+1 停牌递延；长期停牌按复牌首日开盘价 |
| 股票池 | ashare_ex 现行口径（剔除 ST 等），逐日 PIT |
| 成本敏感性 | 往返 0 / 10 / 15 / 25 bp 四档 |
| 容量估计 | 单票买入额 ≤ 当日尾盘成交额的 1%；报告策略总容量 |
| 评估 | 日胜率、日均毛/净收益、年化、夏普、最大回撤、按年度分解（2025=样本内，2026=准样本外） |

## 6. 风险与诚实性约定

1. **高概率负面结论**：结构性先验（隔夜段为负 + 年化 ~37% 摩擦）对本策略极不友好。负面结论可接受、直接入档，不粉饰。
2. **样本短**：1min 精确执行仅 2025-01 起（~407 交易日）；日线近似的 2022-2024 样本只能给方向参考。
3. **可成交性风险**：若最优子集集中在微盘股，开盘竞价可能根本卖不出目标量——Q4 的折损估计必须进最终净值，不许只报毛收益。
4. **多重检验**：信号池封顶 8 个，不做参数精调（阈值只用粗分位），报告按此口径的检验数量。
5. **执行时点现实性**：14:56 买入假设可全额成交；尾盘流动性通常好，但需在 Q4 抽样验证大额成交占比。
