# 因子评价框架综述：从标准维度到深度维度

> 立项：2026-09-12。定位：因子评价方法论综述 + QuantLab 落地路线。
> 背景：因子湖 312 因子（38 风格 + 180 Alpha191 + 后续），生产模型 size+amihud_20 等权 top100（新口径 30.4%/0.94，基准中证1000），候选账本 ~2026-12 双闸门。
> 本文所有标注「本项目实证」的数字均来自湖内可复算结果，脚本路径随文附。

---

## 0. 结论速览

1. **标准体系（IC/ICIR、分组收益、风险调整、稳定性、显著性）是必要条件集，不是充分条件集。** 它们回答"信号在历史上是否伴随收益"，不回答"信号是否为真、能否落地、能活多久、上多大规模"。
2. 六个深度维度按重要性排序（A 股个人/中小资金研究语境，第 9 章给完整论证）：
   **R1 鲁棒性与因果性 > R2 交易成本敏感性 > R3 经济逻辑与可解释性 > R4 拥挤度与容量 > R5 状态依赖性 > R6 跨市场普适性。**
3. 六维度按因子生命周期归位为**三层闸门 + 一层终审**：
   - 真伪闸门（R1+R3）：是不是真的——排除噪声、排除偏差、要求机制；
   - 可用闸门（R2+R4）：能不能用——净收益为正、容量内可实现；
   - 组合层 A/B 终审：值不值得上——本项目五次实证"IC 好 ≠ 组合好"，因子层一切指标只是必要条件；
   - R5/R6 为贯穿全程的辅助维度（归因、旁证），择时类证据未过多重检验不进决策链。
4. 本项目已有 R1 的半个体系（PIT 审计 311 因子 0 FAIL）和 R2 的实证经验（盈亏平衡成本口径），最稀缺的增量是**全库多重检验校正**与**参数扰动鲁棒性扫描**——两者只用既有数据即可落地。
5. **第二梯队扩展标准（E1–E10）见 §12**：转移系数（TC）、多空不对称性、周期完备性等十项；其中 E1/E2/E3 把既有实证教训形式化为可计算指标，建议提升入主框架。

## 1. 标准评价体系：业界与学术界的主流维度

### 1.1 IC 家族（信息系数）

**定义与用法**：因子截面值与下一期收益的截面相关。RankIC（Spearman）优于 Pearson IC——对极端值稳健，且与秩组合收益直接对应。派生指标：

| 指标 | 含义 | 局限 |
|---|---|---|
| IC 均值 | 平均预测力 | 不含稳定性信息 |
| ICIR = mean/std | 稳定性调整后的预测力 | 仍假设预测力线性可加 |
| IC t 值 | 显著性 | 忽略搜索了多少个因子（见 R1） |
| IC 衰减曲线 | t+1 ~ t+20 预测力衰减 | 决定换手下限（见 §8.2） |

**口径纪律（本项目已固化的）**：剔除上市 <60 日 / 停牌 / 一字板样本；A 股基本面因子**必须先 size 中性化**（硬口径：中性化后 cfp_ttm +143bp、np_q_yoy +87bp、ocf_to_profit +98bp、rev_q_yoy +56bp，ROE 族归零）；因子值与收益都必须 PIT。

**核心盲区**：IC 是**全截面统计量，组合只吃尾部**。本项目五次实证（`scripts/diag_ic_vs_portfolio.py`）：rank 混合把组合拉向中盘、换手翻倍 → ICIR 升、收益降。IC 高的因子可能只在中段贡献统计量，头部（真正买入的部分）无差异；反之头部极强、中段混乱的因子会被 IC 低估。

### 1.2 分组收益（分层回测）

十分位分组的多头组/空头组收益、组间单调性、多空组合 Sharpe。**A 股现实约束**：融券标的少、成本高、可借券窗口短 → 多空不可实现，应以**纯多头/相对基准超额**为主口径。盲区：①分组收益默认零成本，掩盖换手差异（第 5 章详述）；②分组边界股票在相邻组间跳变，头部稳定性被平均掉；③多空收益里空头端贡献可能来自卖空约束造成的持续高估（A 股小票空头逻辑尤其失真）。

### 1.3 风险调整与增量信息

- **因子模拟组合**（Fama-French 方法）：控制其他风格后因子是否仍有溢价；
- **回归 alpha**：对 CAPM/FF3/FF5/Barra 风险模型回归后的残差——区分 β 收益与 α 收益；
- **正交化增量**：对既有因子库回归后的残差 IC——增量信息而非绝对预测力（对应"与生产组合的边际贡献"，§8.1）。

盲区：只对**已知**因子正交，无法处理"未知但相关的机制"；风险模型本身有估计误差（Barra 风格因子间相关）。

### 1.4 因子稳定性

分年度 IC 一致性、滚动窗口表现、构造参数（分组数/平滑窗口/中性化方式）敏感性、头部持仓重合度（churn）。盲区：稳定性是相关概念不是因果概念——一个因子可以十年稳定地在 2015 和 2024.02 各爆一次尾部（见 §8.3）。

### 1.5 统计显著性与多重检验

- Newey-West 修正（IC 序列自相关）只是入场费；
- **多重检验**才是现代门槛：Harvey-Liu-Zhu (2016) 调查 316 个已发表因子后建议 t 值门槛从 2.0 提到 **3.0**；White (2000) Reality Check、Hansen (2005) SPA、Bailey & López de Prado (2014) Deflated Sharpe Ratio 把"试了多少次"折进显著性门槛；
- **复现危机**：Hou-Xue-Zhang (2020) 对 452 个异象严格复现，约 65% 无法通过；Jensen-Kelly-Pedersen (2023) 用贝叶斯框架得出 82% 可复现但幅度大幅缩水——学术界对严重程度有分歧，对"**已发表因子的收益幅度系统性高估**"没有分歧（McLean-Pontiff 2016：样本外衰减约 26%，发表后约 58%）。

### 1.6 标准体系的系统性盲区（本项目实证汇总）

| 标准维度 | 核心盲区 | 对应深度维度 |
|---|---|---|
| IC/ICIR | 全截面 vs 组合尾部；无条件口径 | 组合层 A/B 终审、R5 状态依赖 |
| 分组多空 | 忽视换手成本；A 股空头不可得 | R2 交易成本 |
| 风险调整/正交化 | 只对已知因子；不问机制 | R3 经济逻辑、§8.1 增量信息 |
| 稳定性 | 参数稳定 ≠ 因果；尾部风险不可见 | R1 鲁棒性、§8.3 尾部风险 |
| 显著性 | 单因子口径，忽视搜索空间 | R1 多重检验 |
| （无对应） | 拥挤度、容量、跨市场、衰减 | R4/R6/§8.2 |

**本项目五条盲区的实证注脚**：①as-of 股本口径让 PROD 年化虚高 6.3pp——IC 显著但含偏差；②半仓滚动毛 +14.8%/净 −4.4%——分组口径优、成本口径死；③拥挤/估值择时全负——无条件结论掩盖状态结构（且择时本身也不该无条件上）；④rank 混合 ICIR 升收益降——统计指标与组合目标背离；⑤容量 PROD 1.59 亿——历史回测完全不反映规模约束。

## 2. 深度维度 R1：鲁棒性与因果性

### 2.1 研究价值

**这是其他一切维度的地基。** IC、组合收益、成本弹性、拥挤度，全部建立在"信号不是噪声、不是偏差、不是数据挖掘产物"之上。

1. **多因子库的第一性问题**。312 因子库中 Alpha191 类价量因子是典型"数据挖掘优先、机制事后补"的产物。在 300+ 因子上搜索，纯噪声按 5% 显著性水平也会"发现"十几个显著因子——**不校正多重检验，IC 排名近似噪声排名**。本项目 size 的 IC 曾被污染口径高估 17%（−0.0667 → −0.0555），说明连最基础的因子都可能带系统偏差。
2. **前视/幸存者偏差是因果性的最低门槛**。本项目一个月内连环修掉的案例构成完整教材：as-of 股本 join（口径性偏差）→ gpoa_chg/sue_gpoa 按行数取滞后（真穿越）→ universe 用当前状态构建（幸存者偏差，universe_daily PIT 重建根治）。**PIT 审计 311 因子 0 FAIL 只证明"无穿越"，无穿越 ≠ 有效**——WF 复验未做之前不进合成候选，这条纪律已经是对本维度的正确实践。
3. **参数鲁棒性区分"规律"与"巧合"**。真规律对构造细节不敏感；对平滑窗口 ±20%、分组数 5/10、中性化方式敏感的因子，大概率拟合了噪声的特定形状。Alpha191 的 73 个因子尤其需要这个检验——它们的构造式里充满任意常数。

### 2.2 衡量思路

1. **前视审计**（已有）：`_PIT_LE` 截断重放 + 快照表三分法 + `_audit_gate` 拒绝入合成。属因果性的"数据输入干净"层。
2. **参数敏感性扫描**：构造参数网格扰动下 IC 与组合指标的分布（鲁棒性曲面）。报告"参数邻域内指标的最差值"而非均值。
3. **Placebo 检验**：因子值整体时间平移 t+1 日后预测力应归零（不归零 = 有残留结构性偏差，如行业/规模暴露本身）；随机打乱截面因子值，IC 应归零。
4. **子样本折叠**：leave-one-year-out；多起点（不同起始日）重采样。
5. **多重检验校正**：全库 IC 序列做 BH-FDR；组合指标做 Deflated Sharpe / Hansen SPA——把"这个因子是从多少个候选里挑出来的"折进显著性。
6. **因果识别（研究级）**：自然实验做 DID/断点——2023-08 印花税减半、涨跌停/注册制改革、2024-08 北向实时披露停止、退市新规；这些制度断裂提供了罕见的"处理组/对照组"。

### 2.3 实现难点

- 金融数据无法 RCT；样本高度自相关，**有效样本量远小于表观样本量**（1300 个交易日可能有 <200 个独立截面）；
- 因果识别依赖制度断裂，可遇不可求，且断裂常与宏观周期混杂（注册制推进期恰逢小票行情）；
- 全库扫描的算力：312 因子 × 参数网格 × 子样本折叠需批处理——本项目已有轮询等锁编排经验（`post_rebuild_20260912.py`）可复用；
- 灰区归类需要判断："鲁棒但无逻辑"（可疑）与"敏感但有效"（换手型高频信号天然敏感）不能机械一刀切。

### 2.4 适用场景

因子入库前最后闸门（IC/组合指标之后）；数据源升级/口径切换后的全库复检（as-of 事件正是案例）；外部因子/论文因子引入评估；`append_factor keep="last"` 类工程陷阱的制度化防线（换口径必 `--rebuild`）。

### 2.5 本项目现状与增量

已有：PIT 审计体系（311 PASS）、WF 闸门、双闸门机制、假 PASS 修复。缺口：**placebo 检验、参数扰动扫描、全库多重检验校正**三件套均未做——这是综述结论里 P0/P1 落地项（第 10 章）。

## 3. 深度维度 R2：交易成本敏感性

### 3.1 研究价值

**唯一决定"研究成果能否变成钱"的维度**，也是本项目实证否决率最高的维度。

1. 本项目最锋利的一条实证：**半仓滚动毛 +14.8%/年、净 −4.4%，盈亏平衡 13.5bp/往返**——毛收益口径下它是策略，净收益口径下它是亏损。rank 混合把换手翻倍后 ICIR 升、收益降，同样死在成本上。hf_wf/a191_wf composite 也全部死在组合层（换手是主因之一）。
2. **A 股成本结构特殊且非线性**：佣金+规费双边约 5~8bp、印花税卖出单边 5bp（2023-08 减半后）、冲击成本随参与率非线性放大；涨跌停制造"流动性黑洞"——想买买不到、想卖卖不掉，成本在极端时刻从 bp 级跳到无穷大。2024.02 微盘踩踏是教科书案例：连续跌停下中性产品无法减仓，实际成交成本远超任何模型的估计。
3. **成本与 alpha 内生相关**：高 alpha 常在低流动性票上——amihud 本身就是本项目生产因子（非流动性溢价），这意味着**容量天然受限是同一枚硬币的两面**。按"毛收益排序后扣同一成本"的处理会系统性错排这类因子。

### 3.2 衡量思路

1. **盈亏平衡成本** = 年化毛超额 / 单边年换手，与实测成本结构（佣金+印花税+冲击估计）对比留安全边际。13.5bp/往返的半仓滚动基准已在手。
2. **净收益曲线族**：单边成本 5/10/20/40bp 扫描下的净 Sharpe——看衰减斜率而非单点。斜率平缓 = 成本不敏感；斜率陡峭 = 换手依赖型，任何成本估计误差都致命。
3. **换手分解**：信号自然换手（由因子半衰期决定，不可压）vs 再平衡规则换手（缓冲带/分层调仓可压）。只压后者才有意义。
4. **冲击成本模型**：平方根模型 σ·√(Q/V) 加涨跌停约束修正；用成交额参与率上限（κ≈5%）反推容量（与 R4 共享基础设施）。
5. **可成交性压力测试**（已有雏形）：剔除封板/大涨>7% 几乎不影响收益（30.4→30.6/30.4%）说明生产模型对可得性约束稳健，但这是粗代理口径——完整版应做逐笔重放（a-share-tradability-auditor skill 的规格目标）。

### 3.3 实现难点

- 冲击成本不可直接观测：回测成交价是理想化的，真实成交分布在盘口与日内时序上（本项目买入时点研究恰好证明日内结构重要：开盘 +10.31bp vs 尾盘 −7.29bp）；
- 成本与 alpha 内生相关 → "扣成本后排序" ≠ "毛排序扣成本"，需在组合构建层联立评估；
- 成本参数本身随市场状态变化（波动放大时冲击翻倍），单点成本假设在压力期失真。

### 3.4 适用场景

一切要上生产的因子/模型的**硬闸门**（本项目已事实执行：半仓滚动、rank 混合均被净收益否决）；执行优化（买入挪开盘白捡 9~18bp 已实证）；换手控制设计（缓冲带、信号平滑、分层调仓）。

## 4. 深度维度 R3：经济逻辑与可解释性

### 4.1 研究价值

**"统计上真"与"经济上真"是两条独立证据链**：R1 回答"信号是否稳定存在"，R3 回答"为什么应该存在"。与 R1 构成双支柱——两者同时成立的因子，样本外存活率和半衰期显著更好。

1. **先验收缩的依据**：面对一个 t=2.5 的因子，有没有可信机制决定了该给多少信仰。这既是 Harvey 等提高 t 门槛的替代方案，也是风格因子投资行业的基本纪律（Cochrane 2011 三分法：期望收益差异 = 风险补偿 / 行为偏差 / 结构摩擦——三种机制的半衰期与尾部特征完全不同）。
2. **失效归因能力**：有逻辑的因子失效可以诊断——逻辑被套利消失（alpha 衰减，砍仓）、逻辑仍在但处于不利状态（周期，持有或加仓）、逻辑从未成立（数据挖掘，复盘找偏差）。无逻辑因子失效只剩"止损离场"一个动作。
3. **组合层的真分散**：逻辑同源的因子叠加是伪分散（各种反转族本质是同一件事）；机制互补（风险溢价 + 行为偏差 + 结构摩擦）才能降低联合回撤。本项目生产组合 size（风险补偿+制度性）+ amihud（结构摩擦）恰好机制互补——这是它能活的隐性原因之一。

### 4.2 衡量思路

1. **机制登记（事前防合理化）**：入库时强制三分类（风险补偿/行为偏差/结构摩擦）+ 一句话可证伪机制假说。事后补故事没有证据价值。
2. **逻辑的可证伪预测**：若 amihud 是流动性溢价，其收益应集中于流动性收紧时期、空头端应有流动性风险暴露；若因子是处置效应（行为），散户持仓高的股票上应更强。用数据检验机制含义，而非只看收益——机制预测被数据支持，才叫逻辑成立。
3. **新颖度检验**：对既有风格库正交回归，残差 IC 才是增量（与 §1.3 衔接）。
4. **与制度结构的一致性**：A 股 T+1、涨跌停、散户主导、融券受限——机制必须与这些制度兼容。涨跌停磁吸、打板资金、壳价值这类 A 股特色机制文献少，需要自建验证，也是本土研究的机会。

### 4.3 实现难点

- **事后合理化（narrative fallacy）是本维度最大敌人**：给任何统计模式都能编故事。防线 = 事前登记 + 可证伪预测，两者缺一不可；
- 机制验证需要状态变量与分组变量，它们自身有测量误差和 PIT 风险（本项目教训：分档变量必须 PIT，当日成交额是结果不是信息）；
- 机制的强度难以量化排序——本维度输出多为定性分级（强/中/弱/无），不像 IC 那样有连续刻度。

### 4.4 适用场景

入库分级（强逻辑+弱统计 → 观察池跟踪；强统计+无逻辑 → 挂"数据挖掘嫌疑"重检）；长期配置权重（逻辑决定持有信心）；失效诊断（区分三种失效模式）；组合内真分散的结构设计。

## 5. 深度维度 R4：拥挤度与容量

### 5.1 研究价值

1. **崩塌预警**。因子收益的微观基础是"别人还没发现/还没用"，拥挤是 alpha 的天敌：拥挤 → 抢跑 → 信号前移衰减 → 极端时同向平仓共振。案例谱系：2007-08 quant quake（Khandani & Lo）、2021 A 股抱团瓦解、**2024-02 A 股微盘/DMA 踩踏**（size/微盘暴露产品连环强平，中证2000 单月级回撤）。本项目生产模型 = size top100，**正是小市值暴露，2024.02 型风险直接相关**。
2. **容量 = 策略的商业价值上限**。本项目实测：PROD 1.59 亿 / EQ3 1.86 亿 / PROD_SI 2.38 亿（±5% 存活）。对个人研究资金不构成约束，但决定任何未来资管化路径的规模天花板，也解释了为什么 EQ3/PROD_SI 的流动性画像"更优"是切换候选的加分项。
3. 拥挤度是 **alpha 半衰期的监控代理**：因子在机构持仓中占比上升 → 未来收益分布左移。这把本维度与 §8.2 衰减动力学连起来。

### 5.2 衡量思路

**容量（事前估计）**：
- 参与率模型：组合单票调仓量 ≤ 该票日成交额 κ%（κ≈5%），反推最大 AUM；
- AUM 扫描下的净收益曲线，找衰减拐点（本项目 ±5% 收益存活口径即是此法的简化版）。

**拥挤度（运行时监控代理）**：
- 因子多头组合与公募重仓重合度（季度披露，滞后）；
- 两融余额在多头组合上的因子暴露；
- 多头组合内部配对相关性上升（相关性骤升 = 持仓趋同）；
- 因子估值价差（factor valuation spread：多头组估值分位 − 空头组，Arnott 系机构主张的核心指标）；
- 换手/成交额集中度；A 股特色：龙虎榜营业部集中度、涨跌停封板资金结构。Lou & Polk 的 comomentum（动量拥挤指标）是学术范例：拥挤动量 → 动量崩塌概率上升。

**崩塌条件研究**：拥挤 × 杠杆 × 流动性三因子共振的识别（2024.02 = 三者同时到顶：微盘拥挤 + DMA 杠杆 + 跌停流动性黑洞）。

### 5.3 实现难点

- 冲击成本模型在 A 股失真（涨跌停黑洞、日内 U 型成交分布）→ 容量估计只能给数量级；
- **拥挤 ≠ 必然崩塌**：可拥挤多年不崩，时点不可预测——拥挤度只能做风险预算与预警，不能做精确择时（本项目"拥挤/估值择时全负"的实证与文献争论一致：AQR 系认为因子择时极其困难，Research Affiliates 系主张估值价差可用，长期无共识）；
- 数据源持续劣化：公募持仓季度滞后、北向实时披露 2024-08 起停止。

### 5.4 适用场景

上线前容量评估（机构场景为硬闸门；个人场景为能力边界记录）；存量策略拥挤度监控（建议纳入数据看板——size top100 的微盘暴露使这不是可选项）；多策略资金分配（容量作为权重分母）；崩塌应急预案（拥挤触发阈值 → 降仓规则的预登记）。

## 6. 深度维度 R5：状态依赖性（条件因子与因子择时）

### 6.1 研究价值

1. **无条件口径低估条件因子**：均值 IC 低但条件结构有信息的因子，可能在特定状态有强预测力。标准体系把这类因子平均掉了。
2. **因子择时是学术界持续二十年的争论**：Arnott 系（估值价差可择时）vs AQR 系（逆势因子择时极其困难）至今无共识；较稳的正面证据是**因子动量**（Gupta & Kelly 2019 "factor momentum everywhere"；Ehsani & Linnainmaa 2022）——因子自身近期表现延续。
3. **失效归因**：区分"周期性失效"（状态回归后恢复）与"永久性失效"（机制死亡）——这决定砍仓还是加仓，是投资决策的真问题。

### 6.2 衡量思路

1. **条件 IC 回归**：IC_t = a + b·S_{t−1} + e。状态变量 S 候选：波动率状态（VIX 型代理）、信用/流动性状态、散户活跃度（两融余额、全市场换手）、规模风格轮动（大小盘收益差）、因子自身估值价差。**b 的显著性必须做多重检验校正**（状态变量 × 因子的搜索空间巨大）。
2. **状态分组 IC 差** + 组间检验；HMM/Markov 切换（参数化强、解释弱，慎用）。
3. 状态变量必须 PIT：宏观指标有发布滞后与事后修正，用发布日不用统计日（本项目 InfoPublDate 纪律的宏观版）。
4. A 股特色：制度变迁制造的**结构性断点多于周期性状态**（注册制、量化监管、退市新规）——断点检验（structural break）比状态机更贴合现实。

### 6.3 实现难点

- **切状态后统计功效骤降**：全样本切成每状态几十个月，多重检验维度爆炸——这是"因子择时难"的统计学根源，也是本维度排名不能靠前的核心原因；
- A 股状态结构不稳定（三十年走完美股百年制度变迁），历史状态划分的外推性弱；
- 本项目实证：**拥挤/估值择时全负**——简单状态变量 + 简单规则的因子择时不可依赖，这条负面结论应被尊重而非反复重试。

### 6.4 适用场景

失效归因（周期 vs 永久的诊断报告）；风险预算的定性调整（拥挤度升 → 降 size 暴露的人工决策依据）；**不建议**作为因子选择/权重调整的自动化决策链输入——至少在全库多重检验校正之前。定位：归因工具 > 决策工具。

## 7. 深度维度 R6：跨市场普适性

### 7.1 研究价值

1. **经济逻辑真实性的独立证据链**：行为偏差（锚定、处置效应、彩票偏好）应在多市场存在；纯制度套利（壳价值、涨跌停磁吸）只在本市场存在。经典启示：动量在美股强、A 股弱而反转强（Chui-Titman-Wei 2010 的个体主义文化解释）——跨市场对比本身就是"哪些 alpha 是人类行为、哪些是制度"的判别器。
2. **因子寿命判断**：制度套利型因子寿命 = 制度寿命（注册制推进即侵蚀壳价值逻辑）；行为型因子寿命 = 人类本性修正速度（慢得多）。
3. **对冲发表偏差**：只在本市场样本显著的因子更可疑；在多市场重复出现的因子，"数据挖掘"解释需要更长的杠杆。

### 7.2 衡量思路

- 同构因子跨市场 IC/组合对比（A 股 vs 港股 vs 美股 vs 期货/债券），关注**存在性与幅度排序**而非精确相等；
- 结构差异归因：散户占比、T+1/T+0、涨跌停、做空约束——把市场制度差异当作自然实验；
- 汇率、会计准则（US GAAP/IFRS/中国准则）、披露制度对齐后重测。

### 7.3 实现难点

- **数据工程成本最高的维度**：跨市场 PIT 数据、财务口径对齐、复权口径，每一项都是独立项目；
- 因子定义可比性漂移：A 股 amihud 在美股的成交结构与含义不同（做市商制度 vs 撮合）；
- 收益是间接的（强化逻辑判断，不直接产生组合）。

### 7.4 适用场景

新因子机制验证的加分项；商业化/出海策略评估；资源充裕时的研究项目。本项目低垂果实：用现有 westock/tdx 港美股通道先做 size/amihud 的跨市场 IC 对照——两个生产因子的普适性检验，一天可出结果。

## 8. 补充维度速览（不展开，但应在框架里占一席）

### 8.1 增量信息与冗余度
对多因子库而言是**排序维度**而非单纯统计步骤：新因子对"生产组合"的边际贡献 > 其独立表现（a191 去重 5 个冗余因子的实践）。衡量：对生产因子正交化后的残差 IC + 与既有组合持仓的重合度。本项目 EQ3 系列反复验证：高相关因子的叠加稀释尾部（overnight 稀释剔除判断被两轮强化）。

### 8.2 衰减动力学
IC 半衰期决定换手下限（与 R2 硬连接）；**发表后衰减**（McLean-Pontiff：−26% ~ −58%）意味着"别人也会发现"；因子动量与因子动量崩溃（Daniel-Moskowitz 2016）提示衰减本身有时变性。衡量：t+k 多期 IC 曲线、滚动窗口收益的趋势检验。

### 8.3 尾部风险
极端区间的因子表现（2015 股灾、2024.02 微盘危机）；CVaR/最大回撤/崩塌日重合度（多因子组合在危机日同跌 = 伪分散）。size 因子在 2024.02 的还债是本项目切身体会——风险溢价型逻辑（R3 的分类）必然带尾部，这应在入库时标注而非事后发现。

### 8.4 组合层匹配度（贯穿性原则，本项目方法论核心）
因子层一切指标（IC/分组/稳定性）只是**必要条件**；终审必须是组合层 A/B：净超额、Sharpe/IR、最大回撤、换手、与既有组合的相关性、头部重合度。五次实证（`scripts/diag_ic_vs_portfolio.py`、batch7/batch8、半仓滚动、rank 混合）构成完整证据链。本框架把这一原则显式化为终审层。

## 9. 维度重要性比较与排序

### 9.1 评价准则与打分

四准则：**真伪判定贡献**（排除伪因子的能力）、**生产决策影响**（上线/否决权重）、**A 股制度适用性**、**实施成本**（数据+算力+工程，低=高分）。权重 35/35/15/15。

| 维度 | 真伪判定(35%) | 生产影响(35%) | A 股适用(15%) | 实施成本(15%) | 加权 | 排序 |
|---|---:|---:|---:|---:|---:|---:|
| 鲁棒性与因果性 | 5 | 4 | 5 | 3 | **4.35** | R1 |
| 交易成本敏感性 | 2 | 5 | 5 | 4 | **3.80** | R2 |
| 经济逻辑与可解释性 | 4 | 3 | 4 | 5 | **3.80** | R3 |
| 拥挤度与容量 | 2 | 4 | 5 | 3 | **3.30** | R4 |
| 状态依赖性 | 3 | 2 | 4 | 3 | **2.80** | R5 |
| 跨市场普适性 | 3 | 1 | 2 | 1 | **1.85** | R6 |

R2/R3 加权并列（3.80），排序打破依据：生产决策的即时性与不可回避性——成本否决每天都在发生（本项目净收益否决率最高的维度），逻辑收益是慢变量；且 R2 数据完全自有（换手/成本结构），不依赖外部输入。故 R2 列前。

### 9.2 排序论证（按项目语境）

- **R1 第一**：它是地基——其余维度全部建立在"信号非噪声"之上；312 因子库的多重检验问题使它在统计上最紧迫；且本项目已投入最多（PIT 审计体系）证明其可操作性，边际成本低。
- **R2 第二**：研究成果变成钱的唯一通道。半仓滚动、rank 混合、hf composite 全部死在成本/换手上——实证否决率最高 = 生产决策影响最大。
- **R3 第三**：决定因子寿命与失效时的应对动作；与 R1 构成双支柱；实施成本最低（登记+检验）但收益是慢变量。生产组合 size+amihud 机制互补的隐性成功是正面证据。
- **R4 第四**：崩塌预警价值高（2024.02 与 size 暴露直接相关），但个人资金下容量不构成硬约束；拥挤度作为**监控指标**价值 > 决策指标（择时实证全负）。
- **R5 第五**：研究价值与过拟合风险同高；功效骤降 + 状态变量难找 + 本项目择时全负 → "归因用途 > 决策用途"。
- **R6 第六**：正确的旁证但数据工程最贵；对纯 A 股个人研究是锦上添花。

### 9.3 语境敏感性（排序的适用边界）

| 语境 | 排序变化 |
|---|---|
| 本项目（A 股、个人/中小资金、312 因子库、已有组合层 A/B） | 如上 R1>R2>R3>R4>R5>R6 |
| 机构资管语境（大资金） | **R4 升至前二**：容量与成本同源（冲击成本 ∝ 规模），容量即生死 |
| 学术语境（识别 vs 预测） | R1 与 R6 升位：因果识别与普适性是发表核心，R2/R4 降为 applied 注脚 |

## 12. 扩展评估标准（第二梯队，2026-09-12 补）

> 追问"还有没有更多评估标准"的产物。十项标准不改变 R1–R6 的头部排序，但其中三项（E1/E2/E3）把既有实证教训形式化为可计算指标，建议提升入主框架。

### E1 转移系数（Transfer Coefficient）与基本定律 —— 建议并入终审层

Grinold-Kahn 基本定律：**IR = IC × √BR × TC**。本项价值：把"IC 好 ≠ 组合好（五次实证）"从经验规律变成可分解的算式——IC 不差、广度不低时，短板只能在 TC（信号→组合权重的转移效率，被 top100 截断、可成交性约束、缓冲带等吃掉）。
- 衡量：TC = 截面 corr(α 预测, 实际主动权重)；对候选模型分阶段报告 IC/BR/TC 三因子分解，定位短板在哪一环。
- 难点：约束组合的实际权重需模拟；TC 有含成本变体（交易成本也吃 TC）。
- 定位：**终审层目前唯一缺失的量化指标**——组合层 A/B 有了，但 A/B 差在哪一环（预测、广度、还是转移）没有分解。

### E2 多空不对称性（长腿可用性）—— 建议并入可用闸门

A 股无低成本做空 → **因子的预测力集中在空头腿 = 不可收割**。小票高估值端常贡献多空收益大头，纯多头组合拿不到。
- 衡量：多空超额分解 = 多头腿相对基准超额 + 空头腿负超额；要求**多头腿自身显著为正**才可上线。
- 难点：基准选择影响分解；与 R3 联动（机制天然在空头端的因子直接降级）。

### E3 周期完备性 —— 建议并入可用闸门

**只测过单一 regime 的因子 = 没测过。**
- 衡量：regime 分段表（2015 股灾 / 2016 熔断 / 2018 熊市 / 2019-20 白马 / 2021 抱团瓦解 / 2024.02 微盘踩踏 / 2024-09 快牛）+ 最差 regime 指标 + **未覆盖 regime 清单**显式披露。
- 本项目特殊背景：含 size 的 2022-2024 回测刚因口径作废须重算，正好按全 regime 重做；因子湖大量因子 2021-2022 起才有数据，**因子年龄是硬约束**——只能标注不能补。

### E4 对手盘稳定性（alpha 供给端监控）

因子收益需要有人持续卖给你。对手盘是散户行为（稳定但随机构化缓慢萎缩）还是独家数据加工（公开即衰减）？
- 衡量：散户成交占比趋势、信号可观测性分级（公开 OHLCV / 需加工 / 独家）、多头组合估值差。
- 难点：只能粗代理。定位：R3 的运行监控延伸。

### E5 数据源可替代性与定义确定性（基础设施级）

工程评估标准。现实教训充足：TDX 全挂、tushare 限时 token、westock nav 1211 行静默截断、fsdb 单点。
- 衡量：因子→数据源依赖图（哪些因子单源即死）；双源交叉验证（share_capital_daily vs valuation_daily 690.8 万行零差异是范式）；SQL/定义版本化 + 独立重算一致性。
- 定位：生产因子过一遍依赖审计。

### E6 信号广度与覆盖依赖

基本定律的另一因子 BR：有效广度 = 独立截面 × 可区分股票数。
- 衡量：IC 序列自相关折减后的有效广度；覆盖率时序/截面分布；覆盖缺失股票收益对照（**缺失本身是否含信息**——基本面因子常隐含"财报可得"选择偏差，偏向大票）。
- 定位：入库报告项。

### E7 Alpha 的日内/隔夜分解（执行层诊断）

alpha 何时兑现决定执行方案——买入时点研究（开盘 +10.31bp）本质是本维度应用；overnight_mom_20 三度证伪是把它当独立因子的反面教训：**诊断维度有效，独立因子不成立**。
- 衡量：daily_segments 分解多头组合隔夜/日内收益。
- 难点：分钟湖 2025 起才有，历史段不可做，只能前向积累。

### E8 制度暴露审计

A 股因子组合的隐性政策 beta：退市新规（2024 直接冲击微盘）、减持规则、程序化交易监管。size top100 对退市新规的暴露是活例子。
- 衡量：组合退市风险分（市值/营收距临界值分布）；监管事件 study；机制登记字段扩展"制度依赖"标签。
- 难点：政策不可预测，只能计量暴露不能预防。

### E9 组合构建敏感性（生产前工程标准）

同一信号在不同实现规则下的稳定性：等权/市值权/优化器、约束集、调仓缓冲——因子层评价完全不可见。
- 衡量：多构建规则 A/B 矩阵；权重输入扰动蒙特卡洛（估计误差放大系数）。
- 与 E1 互补：**E1 管转移效率，E9 管实现方差**。

### E10 证据协议升级（R1 的方法论升级件）

预注册（假设先行，防事后合理化）、贝叶斯先验更新（JKP 框架：因子库集体证据作为单因子判断的先验）、holdout 纪律（终极封存样本只碰一次）。
- 难点：纪律靠流程不靠工具；holdout 一次性。长期看这是最值钱也最难坚持的升级。

## 13. P0 + E1 落地记录（2026-09-12 实施）

### 13.1 P0-1 全库 BH-FDR 多重检验校正

- 工具：`scripts/fdr_multitest.py` → `reports/fdr_factor_ranking.{json,md}`
- 口径：t_adj = |ICIR20|·√N_eff，N_eff = N·(1−ρ)/(1+ρ)，ρ=0.9
  （IC20 相邻序列共享 19/20 收益窗口，自相关折减——不做此修正
  t>3.0 幸存 258 个、q<0.05 幸存 276/311，等于没筛）。
- 结果：**t>3.0（HLZ）幸存 258→124 个；q<0.05 幸存 164/311**。
- 核心因子分化（诚实记录的张力）：
  - amihud_20 t=3.73 ✓HLZ、q=0.0007；overnight_mom_20 t=4.02 统计最强
    ——但后者已三度执行层证伪，**"统计真≠可收割"的活体注脚**；
  - size t=1.79、q=0.12 **不过显著闸门**——它活在组合层 A/B 证据
    （PROD 30.4%/0.94）而非因子层 IC 证据上，与其"结构性小票效应
    风险溢价"定性一致。因子层初筛与组合层终审的分层逻辑由此坐实。
  - sue_i t=2.91 差 0.09 未过 HLZ 但 q=0.009 过 FDR；hf_amihud_20 t=2.49/q=0.027 过 FDR 未过 HLZ。

### 13.2 P0-2 + E1 候选 A/B 盈亏平衡成本与转移系数

- 工具：`scripts/candidate_ab_breakeven_tc.py` → `reports/candidate_ab_tc_20260912.{json,md}`；
  引擎 `quantlab/optimize/backtest.py` 内置 TC 仪器化（tc_avg，纯增量字段）。
- 盈亏平衡成本（毛超额/年换手，对照引擎 35bp）：
  - 全部 9 模型 600–1113bp，**安全边际 16–31 倍**——20 日调仓+缓冲
    把年换手压到 258–482%，成本维度全部大幅富余；
  - PROD_HFA 1113bp/30.8× 最高，V3_SI 599bp/16.1× 最低（rank 混合
    换手高的代价在成本弹性上显形，与其"ICIR 升收益降"旧实证互证）。
  - ⚠️ 口径注意：该指标衡量"成本翻倍也死不了"，不代表大资金可复制
    ——真实约束是冲击成本非线性（R2 已述，amihud 与容量的内生对冲）。
- 转移系数 TC（FOCUS 窗口，corr(score, 主动权重)，11–15 期）：
  - PROD 0.239 最高；PROD_HFA 0.229、EQ3_HFA_ICW 0.227；

    IC/覆盖增量——TC 把"IC 好≠组合好"分解到了具体环节。
