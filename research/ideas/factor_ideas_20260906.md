## A 类：P0 —— 数据已具备，可直接开工

### A1. SUE / PEAD 盈余惊喜（预期外盈利）
- **来源**：中信证券《SUE因子》、申万宏源《真实超预期系列》（邓虎，2023-07）、华创《季度业绩超预期因子》、华泰多因子系列九
- **逻辑**：业绩公告后股价沿预期差方向漂移（PEAD）。预期净利 = 去年同期 × 过去8季度同比外推；SUE = (实际 − 预期) / 过去8季度 SUE 标准差
- **数据**：东财业绩表 RPT_LICO_FN_CPD（自带营收/净利同比 YSTZ/SJLTZ），管线已接
- **研报基准**（需自行验证）：月度 RankIC 5.1%~6.4%，多空年化 20%~24%，中证1000 内更优（ICIR 1.01）
- **改进版 SUE_I**（申万）：业绩预告 + 快报 + 正式财报三源合并，回看 3 个月时间线性加权，剔除金融地产；无财报月用一致预期变化率替代
- **工程注意**：
  - NOTICE_DATE 是最近修订日而非首披日 → 用 notice_eff = min(notice, 法定披露截止)（已有方案）
  - 财务按报告期记账（date=report_period）；事件窗口用 RANGE INTERVAL
  - 同日披露多期 → ASOF 前先 QUALIFY ROW_NUMBER 去重
  - 非对称性：高超预期显著跑赢，低预期不会大幅跑输（华创）→ 多头端做排序比空头端可靠

### A2. 盈利加速（利润二阶导）
- **来源**：海通《选股因子系列研究(八十三)：盈利加速的定量刻画与高增长组合的构建》（2022-08）
- **逻辑**：用净利润增速的变化率（Δ增速 = 当期同比 − 上期同比）刻画盈利动能拐点；比静态 growth_yoy 更领先
- **数据**：东财业绩表，已具备
- **工程注意**：与现有 revenue_growth_yoy / profit_growth_yoy 做冗余检查（|ρ|>0.7 只留一个）；负基数期（上年亏损）的同比失真需剔除或用绝对额差分

### A3. 隔夜 / 日内收益拆分族
- **来源**：中信建投《市场微观结构系列》（2025-12）分时段思路的日频版；海通"日内分时成交中的玄机"
- **逻辑**：日频数据中 open/prev_close/close 隐含两个独立信息段——隔夜收益（overnight = open/prev_close − 1）与日内收益（intraday = close/open − 1）。研究显示隔夜+早盘信息正向预示，尾盘信息负向预示（过度反应反转）
- **候选因子**：
  - `overnight_mom_20`：20日隔夜收益均值（隔夜动量）
  - `overnight_ratio_20`：隔夜收益占总收益比例
  - `overnight_vol_ratio`：隔夜波动 / 日内波动
  - `intraday_reversal_5`：日内收益短期反转
- **数据**：日频 OHLC 已具备；Alpha191 中散落相关项但未系统化成族
- **工程注意**：一字板日（high=low）隔夜收益失真，需剔除或单独处理

### A4. 筹码分布族（华泰 AI105 低配日频版）
- **来源**：华泰《人工智能105：基于筹码分层结构的端到端AI因子》（2026-06）
- **逻辑**：VWAP 中心三角分布 + 换手率递推估计筹码分布（**纯日频可算**）。研报对照实验显示人工构造的筹码特征也有显著 alpha（端到端版 RankIC 12.3%，多头年化超额 32.5%）
- **候选因子**：
  - `chip_profit_ratio`：获利盘比例（现价上方筹码占比）
  - `chip_bias`：现价相对筹码加权平均成本的乖离
  - `chip_age_short_ratio`：短龄筹码（1~10日）占比 —— 华泰消融实验中筹码龄分层贡献最大
  - `chip_concentration`：筹码集中度（如 80% 筹码价格区间宽度）
- **数据**：日频 OHLC + 换手率/成交量，已具备
- **工程注意**：递推需处理除权（用后复权价格）；长期停牌股筹码"冻结"；注意与 price_position_250（250日价格位置）的冗余——获利盘比例与价格位置相关性可能高，需检查

### A5. 高/低位放量事件簇（国盛"量价淘金"日频近似）
- **来源**：国盛《"量价淘金"选股因子系列研究(十八)》（2026-08）；绝对收益策略年化 18.31%、IR 2.09（研报口径，需自行验证）
- **逻辑**：价格分位（高位/低位）× 成交量分位（放量）组合成事件；高频版上千种事件信号，日频近似版：`t日量分位 > 80% 且 价格处60日高位/低位` 计为事件，统计过去 N 日事件数与信号方向
- **数据**：日频 OHLCV，已具备
- **工程注意**：**事件窗口方向是致命陷阱**——`t日值 = Σ(过去N日事件)` 要求事件向未来扩散（`k.date BETWEEN e_d AND e_d+N`），写反等于预知未来（skill 已有该教训，ICIR 从 +2.3 变 −1.1）；方向性检验（事件首次发生前因子值必须为 0）作为上线闸门

### A6. 两融资金流（北向停披后的替代）
- **来源**：国联民生金工（2026-08-16）
- **逻辑**：融资净买入 − 融券净卖出（个股加总→行业/个股层面），Barra 市值中性化后取 50 日均值，再看两周环比变化率
- **数据**：东财融资融券接口（datacenter），需接入但同源易接
- **研报效果**：两融因子多头端有稳定负向超额 → 用作**剔除项**（在主动大单头部打分内剔除两融极端行业），策略 2018 年以来费后年化超额 11.8%
- **工程注意**：两融标的池有准入门槛（覆盖偏大市值），需声明覆盖缺口

### A7. 大单资金流 / 主力资金
- **来源**：海通《大单的精细化处理与大单因子重构》《逐笔大单因子与大资金行为》；国联民生
- **逻辑**：东财资金流向按单子规模拆主力/大单/中单/小单净流入；因子如净流入占比、净流入强度
- **数据**：东财资金流向接口，需接入
- **工程注意**：中信建投提醒——机构算法交易"大单化小"使大单定义标准出现偏差，Q3 以来定义漂移需监控；单笔金额与流动性因子 IC 相关可达 0.85（本质是 Half-Alpha），扣流动性暴露后多空收益近乎减半 → 入库前做风格正交

### B1. 股东户数变化（筹码集中度代理）
- **来源**：数据宝/私募排排网统计（2026-08/09）
- **逻辑**：股东户数下降 = 筹码集中（主力吸筹）；连续多期下降信号更强

### B2. 分析师一致预期族
- **来源**：华泰《华泰单因子测试之一致预期因子》（多因子系列九，2018-12）

- **研报基准**：原始因子行业位序化后 ICIR 明显提升（全A 一致预期BP行业位序 RankIC 4.78%、ICIR 0.67）；季度环比 ICIR 更高但换手高、收益多来自空头
- **数据**：东财盈利预测 + 研报评级接口
- **工程注意**：覆盖度约 90%（宽基内），小市值覆盖差；预期数据修订频繁，注意 PIT（用进入数据库的生效日）

## C 类：因子改进方法论（增强现有 41 因子）

### C1. 因子分域（光大量化选股系列 14/15 篇）
- **思路**：同一因子在不同域内差异化计算/加权
  - 截面分域案例：估值因子在**小市值域**依然稳健（大市值域失效）→ 市值加权修复；反转因子按**单季度 ROE 同比**分域（高 ROE 域反转更有效，逻辑：超跌但基本面未坏）
  - 时序分域：因子在不同市场状态（如自身动量分位）下差异化处理
- **效果**（研报口径）：营收同比因子分域后周频 RankIC 从 0.8% → 6.68%；反转从 3.77% → 8.03%
- **落地建议**：优先试 reversal_5/10 × ROE 同比分域、ep/bp × size 分域；分域数 ≤3 防过拟合

### C2. 状态条件激活（Drift Regime，2025 arXiv:2511.12490）
- **思路**：value + 短期反转信号仅在"个股漂移状态"（63 日窗口上涨天数 >60%）激活，状态外置零
- **警示**：论文声称 OOS Sharpe 13，数字过于亮眼大概率有幸存者偏差/微妙前视，**不可直接照抄参数**；但"二值状态闸门 + 简单信号"的构造范式值得小规模试验（A 股 63 日上涨天数>60% 样本稀少，可放宽阈值做参数敏感性）
- **落地建议**：作为 reversal_10 的改进项试验，walk-forward 验证，参数敏感性曲线必须平滑

### C3. 估值异常 EPA（东吴，布林带×估值修复）
- **逻辑**：PE 相对自身布林带的偏离（EPD）→ 用信息比率剔除估值逻辑已变的个股（EPDS）→ 再剔除 Beta/成长/价值风格（EPA）
- **研报基准**：2010-2025 多空年化 17.2%、IR 3.37、胜率 81%、最大回撤 3.1%（月频）
- **落地价值**：与静态 ep/value_pe 互补——是**时序维度**的估值偏离（自身历史比较），现有库只有截面维度

### 第五批执行结果（2026-09-07，SUE_I 改进）

**数据源**：业绩预告 = 东财 RPT_PUBLIC_OP_NEWPREDICT（`quantlab/data/perf_forecast.py`）。实测覆盖：2020Q1~2026Q3 共 **39456 行 / 5433 股**（年报期 ~3000 股强制预告、季报期 200-700 股），97.5% 有净利预告区间、99.5% 有去年同期基数；同股同期多版本披露全保留，按 notice_date 生效取最新。**业绩快报接口免费渠道报表名未命中（5 个变体全空）→ SUE_I 落地为两源版（预告+财报）**，预告的 1-3 个月时效领先已是改进主体。

**实现**（`earnings_surprise.py` 追加，SQL 事件层从 SueFactor/SuePred `_body` 单一来源派生防两遍手写漂移）：

| 因子 | 审查 | IC20 / ICIR（2025-05 同窗） | 说明 |
|---|---|---|---|
| sue（原版对照） | PASS | +0.0313 / 0.549 | 2026 衰减至 0.011（拥挤度 96% 分位印证） |
| sue_pred（预告 SUE） | PASS | **+0.0416 / 0.44**，win 0.73 | 预告净利中值代入 sue 同一 δ/σ 框架；预告披露日记账，参数取披露时点已可见最新财报期（严格 PIT） |
| **sue_i**（90 日时间线性加权融合） | PASS（PIT SKIP：pandas 构造，因果性由事件层传递） | **+0.0436 / 0.695，win 0.76**；h60 达 0.062/1.27 | 财报+预告事件流合并，w=90−age 线性加权；旧信号衰减归零（正对 sue 阶梯固化）。**2026 IC 0.027 vs sue 0.011——衰减缓解** |

**冗余**：ρ(sue_i, sue)=0.86（同源改进版，预期内）；ρ(sue_pred, sue)=0.60。改进版全面占优 → 同位替换 A/B 裁决。

**组合 A/B**（`scripts/batch5_ab_test.py`，4 相位配对）：

| 实验 | focus Δ | full Δ | 相位配对 | 结论 |
|---|---|---|---|---|
| E1: V3 组内 sue→sue_i | +1.4pp | −0.4pp（<1pp 持平） | focus **4/4 全正** / full 微负 | ✅ |
