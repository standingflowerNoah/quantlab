QuantLab 是什么：一套本地化运行的 A 股量化研究系统——从数据采集、因子计算、模型回测到每日决策信号的五层全链路（L1 数据 → L2 因子 → L3 模型 → L4 优化 → L5 决策），全部通过一条命令行（cli.py）驱动，人和 AI 助手共用同一入口。

当前体量（实测）：日K线 585 万行（2022-01-04 起）、分钟线湖 5.19 亿行、因子库 12.9 亿行 / 258 个因子、覆盖 1142 个交易日；生产选股模型 size + amihud_20（年化 32.3% / 夏普 0.98），已进入纸面前向跟踪。

第一部分 · 量化研究的完整流程

量化研究不是"想一个策略→跑回测→看赚不赚"，而是一个可复现、可证伪的闭环。QuantLab 把这个闭环固化成了流程：

1.1 策略构思：想法从哪来

本系统的想法来源有三类，全部落档到 research/ 目录（想法先进 research/ideas/，验证后升级为正式研究文档）：

来源例子（本系统真实案例）结局
经典文献 / 异象A 股小市值溢价、低流动性溢价（Amihud）、短期反转、低波动异象通过，构成生产模型 size+amihud_20
券商金工研报国泰君安 Alpha191 短周期价量因子（191 个）；方正/开源高频"聪明钱"因子因子层有效，组合层被否（见 1.5）
自主数据挖掘龙虎榜净买入因子 dragon_net_20、分红事件套利、因子拥挤度择时多个负面结论，如实归档

原则：先想清楚"这个信号为什么应该在统计上存在"（行为偏差 / 制度约束 / 风险补偿），再动手验证——避免纯数据挖掘出的过拟合幻觉。

1.2 数据获取：湖仓一体 + 质量闸门

QuantLab 接了 10+ 个免费数据源（通达信 / 东财 / 腾讯 / 新浪 / 同花顺 / free-stockdb 等），统一落到本地数据湖。研究默认股票池 ashare_ex（全 A 剔除 ST / 次新<120日 / 北交所）。

质量闸门：每日更新后自动跑 data quality 体检（完整性 / 新鲜度 / 合理性 / 一致性 / 复权抽样 5 类），FAIL 会阻塞下游因子与决策步骤——脏数据进不了研究链路。

1.3 因子分析：IC + 分层回测 + 去冗余

因子是系统的核心资产。统一契约：长格式 date / code / value，Parquet 按年分区落湖（data/lake/factor/<name>/），这样任何因子都能用同一套评估代码处理。

三个标准评估动作：

动作命令回答什么问题
IC 评估factor summary <name> --horizon 20因子值与未来收益的截面秩相关（Spearman）是否显著？ICIR（IC均值/IC波动）是否稳定？
分层回测factor backtest <name> --horizon 20 --quantiles 5按因子值分 5 层，各层收益是否单调？多空两端差多少？（非重叠持有期，避免复利虚高）
去冗余factor corr与已有因子的相关性矩阵，相关>0.9 的只留 ICIR 最高的一个

因子IC(20日)多空年化(h=20)解读
reversal_10+0.062+13.8%（reversal_5 口径）短期反转：跌多了会反弹

全部符合 A 股经典实证规律——这批"老因子"是判断新因子是否只是风格代理的参照系。

1.4 回测验证：多因子合成 + walk-forward 硬约束

单个因子有效 ≠ 组合有效。合成流程（cli.py model backtest）：

  1. 每日截面把因子值 rank 标准化到 [0,1]（抗异常值）
  2. 方向校正：负 IC 因子取反（如 size 做多低值）——手工合成必须带 FACTOR_DIRECTION，漏了结论会失真
  3. 等权/加权合成综合评分 → 取 top N 等权持有，20 日调仓
  4. 扣真实成本：佣金 + 印花税 + 滑点
本系统的硬约束：策略上线前必须通过样本外 / walk-forward 滚动验证。 即"训练窗滚动前移、只评估从未见过的样本外区间"。历史上多次出现全样本漂亮、样本外塌掉的案例（如 overnight_mom_20 单腿 2024 年 −5.3% vs 全期 +6.7%），全被这个闸门拦下。

1.5 结果评估：绩效指标 + 双闸门 + 诚实归档

指标体系：年化收益 / 超额年化（vs 中证1000）/ 夏普 / IR / 最大回撤 / 换手率 / 容量（持仓 ADV 占比）。

关键教训——"因子层通过 ≠ 组合层可用"（双闸门）：

案例因子层 WF组合层 A/B结论
Alpha191 合成 a191_wf_composite✅ OOS ICIR 0.55❌ 全部跑输生产组合（focus −11.8pp）截面正交 ≠ 选股边际贡献；卫星弱于主组合必稀释
高频合成 hf_wf_composite✅ OOS ICIR 0.41❌ 不进实盘加权留库前向跟踪，24+ OOS 月后复评
dragon_net_20—（ICIR 虚高 2.3）—前视 bug：t 日值含未来事件。回测年化 45.7% 作废回退，修复后实测负 IC

这套"负面结论如实归档"的机制是系统最重要的资产之一：research/ 下的每份研究文档都记录了证伪过程，避免后人重走弯路。

2.4 三个关键工程机制

① DuckDB 单写者 + 查询三层降级。DuckDB 同一时刻只允许一个写连接，系统约定：写任务串行（锁冲突立即报错，绝不并发跑两个更新）；查询永不阻塞——本进程连接 → 只读直连 → 写锁被占时自动降级查 Parquet 镜像（数据截至最近一次更新）。所以任何时候 query / data quality / universe 都能跑。

遇到 File is already open in ... (PID xxx) 不要慌：这是单写者在工作（如每日流水线正在跑），读路径会自动降级，等写任务结束即可。本材料编写时就真实遇到了一次（overview_report.py 持锁中）。

② Parquet 是唯一事实源。数据库引擎只是可替换的加速层（Phase 2 规模上去后可换 QuestDB）。分钟级数据 5.19 亿行全在 Parquet 分区里，DuckDB 只挂视图。增量写入前必须做 anti-join 去重，merge 键要统一成 datetime64[ns]——这些坑都已沉淀在更新代码里。

③ 构建即审查 + 双闸门。因子入库自动执行结构/分布/覆盖/IC/PIT 穿越自检，结果存 data/lake/factor_audit/（当前 258 个因子：257 PASS / 1 WARN，实测）；合成层设审查闸门，引用 FAIL 因子直接拒绝；决策层还有前置闸门——任一模型因子覆盖度不足，候选快照整块不记、生产照常。

计算因子（一行 SQL 定义，幂等写盘）

$PY cli.py factor compute reversal_5 --universe ashare_ex

因子定义就是一段 SQL（quantlab/factor/library/price.py，真实源码）：

# 基类：N 日动量/反转，_sign=+1 动量，-1 反转
class _MomBase(SqlFactor):
    def _sql(self, start=None, end=None, universe=None):
        usql, uparams = universe_sql(universe)
        sql = f"""
        {QFQ_CLOSE}
        SELECT date, code,
               {self._sign} * (close_adj / LAG(close_adj, {self.n})
                 OVER (PARTITION BY code ORDER BY date) - 1) AS value
        FROM qfq
        WHERE 1=1 {usql}
        QUALIFY value IS NOT NULL
        """
        return sql, uparams

@register
class Reversal5(_MomBase):
    name = "reversal_5"
    description = "5日反转（-5日收益，短期反转信号）"
    n = 5
    _sign = -1

解读：DuckDB 窗口函数一次算全市场，避免 Python 逐行循环；QFQ_CLOSE 片段自动前复权；写盘幂等（重复跑安全）。入库时自动触发审查（PIT 无前视自检）。

4

IC 评估：这个因子有预测力吗

$PY cli.py factor summary reversal_5 --horizon 20
# 实测结果：IC(20日) = +0.062，ICIR 稳定为正

解读：IC = 每日因子值与未来 20 日收益的截面秩相关。+0.062 的含义：过去 5 日跌得多的股票，未来 20 日倾向于涨（反转效应）。经验参考线：|IC|>0.03 可用，>0.05 较强；更要看 ICIR（稳定性）而非单点 IC。

5

分层回测：单调性才是说服力

$PY cli.py factor backtest reversal_5 --horizon 20 --quantiles 5
# 实测结果（年化）：
#   Q1(最低分位) 1.3%  →  Q5(最高分位) 15.2%，多空 +13.8%，单调性 0.7

解读：按因子值分 5 组，每组持有 20 日（非重叠，防复利虚高）。做多高分位年化 15.2% vs 低分位 1.3%——收益随因子值单调递增，与 IC 方向一致。单调性差、只有两端有差异的因子通常不可信。

6

组合层验证：多因子合成回测

$PY cli.py model backtest --factors size,amihud_20 --n 50 --rebalance 20
# 生产模型实测（2022-01 ~ 2026-09，已扣佣金/印花税/滑点）：
#   年化 32.3% / 夏普 0.98 / IR 1.64
#   可成交性约束（剔除建仓日涨幅>7%股）后 年化 32.0%，仍稳健

解读：rank 标准化 → 方向校正（两因子均做多低值）→ 等权 → top50 等权持有。注意对比：任何新候选模型都要与这个基准 A/B——历史上 Alpha191 合成、高频合成在组合层全部跑输它，这就是双闸门的现实意义。
